# «Терминал 202»: шаблон ingress-дополнения HAOS

Рабочее локальное дополнение было создано на HA200 в `/addons/terminal202`, slug `local_terminal202`; панель **«Терминал 202»**. Оно запускает `ttyd` и из браузера HA200 открывает SSH до HA202 по Tailscale.

Файлы в этой папке — **обезличенный шаблон, восстановленный по журналу настройки**, не побайтовый экспорт с установленного сервера. Для использования заполнить `HA202_TAILSCALE_IP`, `HA202_SSH_HOST_KEY_SHA256` и `HA202_SSH_USER` безопасным способом; никогда не коммитить реальные ключи и значения из конфигурации своей сети в публичный репозиторий.

## Проверено в реальной настройке

- HA200: дополнение `local_terminal202` запущено, `ingress: true`, `ttyd` на 7681, WebSocket-соединение работает.
- SSH-подключение к HA202 действительно работало через Tailscale, по ключу, без пароля.
- Авторизованный SSH public key для Advanced SSH & Web Terminal на HA202 должен быть указан в `ssh.authorized_keys` конфигурации **дополнения**, а не просто создан в `~/.ssh/authorized_keys` его контейнера.
- Для команд диагностики требовался отдельный SSH ключ; его публичное значение здесь не публикуется.

## Сборка и настройка

Этот шаблон требует подстановки адреса и host-key fingerprint в локальную конфигурацию запуска. Исходный установленный вариант использовал сохранённый ожидаемый SHA256-отпечаток `ed25519` сервера, проверяемый до принятия `known_hosts`. В шаблоне значения берутся из переменных окружения и при их отсутствии запуск останавливается.

Не направлять входящий SSH-админ-доступ через прокси во время эксперимента с маршрутами.
