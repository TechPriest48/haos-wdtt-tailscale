# WDTT Tailscale Gateway: настройка и использование

Аддон — **клиент** для существующего WDTT VPS. Он не устанавливает и не меняет сервер.

1. Сделайте резервную копию HAOS. Не полагайтесь только на Tailscale для доступа
   к Home Assistant во время сетевых экспериментов.
2. В панели заполните IP/домен VPS, порт, секрет WDTT и от одного до четырёх VK-хешей.
   SSH-пароль от VPS здесь не нужен. Сохраните стабильный Device ID.
3. Запустите режим «Всегда» с отключённым маршрутом Tailscale.
4. В разделе «Логи» проверьте состояние `connected`, затем убедитесь в наличии
   интерфейса `wg-wdtt` в диагностике.
5. При наличии локального доступа установите в Tailscale-аддоне
   `userspace_networking: false` и убедитесь, что интерфейс `tailscale0` появился.
6. Включайте `route_tailscale` только после успешной диагностики WDTT.
7. Режим `auto` подключает WDTT при повторных сетевых сбоях. Он не может
   гарантированно отличить белый список от аварии мобильной сети.

**Опасность:** аддон имеет `NET_ADMIN` и общую сеть с HAOS; неправильные
правила маршрутизации могут нарушить удалённый доступ. По умолчанию маршруты
остаются выключены. При сбое возвращайтесь к аддону через локальную сеть,
отключайте `route_tailscale` и проверьте логи Supervisor.

Пароли и VK-хеши вводите только в приватные настройки аддона, не в GitHub Issues.
Терминал панели выполняет только ограниченный набор диагностических команд.

Дополнительная документация и описание параметров: [README](../README.md).
